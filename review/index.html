04 / How it works

Deterministic rules around the model.

Open the n8n exports ↗
  1. 01Durable intakeAuthenticated webhooks, signed Shopify ingress, event deduplication.
  2. 02Policy + calculationConsent, cooldown, purchase checks, stock and order metrics.
  3. 03Structured generationGemini or OpenAI, JSON Schema, local grounding checks.
  4. 04Review + outboxSigned Slack decision, persisted jobs, ambiguous-write holds.
  5. 05Audit + readbackSQL state, action receipts, explicit denominators.

The model proposes.
The application enforces.

  • Live mode fails closed; it never silently switches to fixtures.
  • Contact email and customer/cart IDs are removed before generation.
  • Read/model retries are bounded. Uncertain remote writes are reconciled.
  • Product content stays local; customer communications remain internal drafts.
